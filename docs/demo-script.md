# MiniPay 演示脚本

## 演示顺序

1. 展示 `docker compose ps`，说明依赖和服务均已启动。
2. 注册一个新商户，确认注册后自动登录且只能看到自己的商户。
3. 使用 `merchant-demo` 登录并通过可搜索下拉框切换多个演示商户。
4. 创建订单，获得平台订单号。
5. 打开支付页，展示订单金额和状态。
6. 点击模拟支付。
7. 回到商户后台，查询订单状态和支付流水。
8. 进入运营后台，查询订单、流水、事件、通知记录。
9. 对已支付订单再次支付，展示重复支付拦截。
10. 打开 Prometheus 和 Grafana，展示指标。
11. 打开 SkyWalking UI，展示调用链。
12. 打开 GitHub Actions，展示 CI 结果。
